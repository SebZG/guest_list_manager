# Guest List Manager

This project is a simple console-based Guest List Management System built using the C programming language. 

It allows for basic operations such as:

- Set standard and concession prices
- Update guests info
- Delete guests
- Print stats, guests, or all data
- Auto populate list for a quick demo

The system uses a singly linked list to dynamically manage guests in memory. 
Each guest is represented by a guest struct that stores details such as first and last names, if they pay concession or normal price, and wether they have paid.

To run the program simply open a terminal and run the following file:

```bash
glm.exe
```
